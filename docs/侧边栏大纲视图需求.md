# "TOC 侧边栏大纲视图" 功能需求

**文档版本**：v1.0
**适用范围**：MarkdownReader（当前单文件阅读器）
**依赖现状**：主进程 IPC（`open-file-dialog` / `file-opened` 等）、渲染进程 `contextIsolation` 隔离环境、`rawMarkdown` 状态（已在搜索功能中引入）

---

## 1. 功能目标

从**当前打开的 Markdown 文件**中自动提取标题（`#` ~ `######`），在**右侧可折叠大纲面板**中以层级缩进展示，支持滚动时当前位置自动高亮、点击标题平滑滚动跳转。

**本期范围（明确）**：
- 仅针对**当前打开的一个文件**，跨文件跳转不在本期。
- 大纲基于**渲染后的 DOM 标题元素**（`h1`~`h6`）自动生成，无需手动维护目录。
- 大纲逻辑在**渲染进程**内实现，**不新增任何 IPC 通道**，复用搜索功能已持有的 `rawMarkdown` / 渲染结果。
- 与搜索功能共享"滚动 → 内容区"定位机制（`scrollIntoView`）。

**本期不做（明确排除）**：
- ❌ 手动编辑、拖拽排序大纲条目。
- ❌ 大纲的展开/收起标题层级树（仅面板整体折叠/展开）。
- ❌ 跨文件 / 文件夹 / 工作区大纲聚合。
- ❌ 自动滚动定位（滚动位置驱动大纲跟随为"只读高亮"，不做互相联动滚动）。
- ❌ 大纲导出 / 独立打印。

---

## 2. 用户故事

- 作为用户，我希望打开任意 Markdown 文件后，右侧能自动出现一个大纲面板，直观展示文档的标题结构。
- 作为用户，我希望标题按层级缩进显示（H1 > H2 > H3），并可通过前缀图标/加粗区分层级。
- 作为用户，我希望滚动文档时，大纲中对应的标题能自动高亮，让我知道当前阅读位置。
- 作为用户，我希望点击大纲中的某个标题，内容区能平滑滚动到对应位置。
- 作为用户，我希望大纲面板可整体折叠/展开，避免遮挡正文。
- 作为用户，我希望文档没有标题时，面板显示友好空状态提示而不是空白。

---

## 3. UI 设计

**整体布局**：`#content` 子元素结构为 `.markdown-body` 内容区 + 右侧 `#outline-panel`（固定宽约 220px，占窗口右侧）。面板默认展开；无标题或未打开文件时面板隐藏或显示空状态。

**展开状态**：
```
┌────────────────────────────────────────┬──────────────┐
│  #content（markdown-body）              │  📑 大纲  [×] │ ← 面板标题栏
│                                        ├──────────────┤
│  ## 项目概述 …                          │  ● 项目概述   │ ← H1，加粗
│                                        │    ○ 背景介绍 │ ← H2，缩进16px
│                                        │    ○ 核心功能 │
│  ## 安装指南 …                          │  ● 安装指南   │ ← 当前高亮项
│                                        │    ○ 环境要求 │
│                                        │      ▪ 系统要求│ ← H3，缩进32px
│                                        │      ▪ 依赖列表│
│                                        │    ○ 快速开始 │
│                                        │  ● API文档    │
└────────────────────────────────────────┴──────────────┘
```

**折叠状态**：面板整体收起，仅保留一条窄边（或右侧"大纲"浮动按钮）用于重新展开，不遮挡正文。

### 各元素说明
- **标题栏**：`📑 大纲` 文本 + 右上角 `[×]` 关闭按钮（点击折叠面板）。
- **条目图标**：H1 用 `●`、H2 用 `○`、H3 用 `▪`，H4+ 可用 `·` 或不带图标；图标随层级递减字号。
- **层级缩进**：每深一级缩进 `16px`。
- **当前高亮**：当前所在标题项使用主题强调色（如 `--color-accent-emphasis`）背景 + 加粗文本。
- **空状态**：`该文档暂未检测到标题` 居中灰字提示。

## 3. 交互流程

```
1. 打开 Markdown 文件成功后
   → 自动提取标题生成大纲
   → 若有标题：面板自动展开
   → 若无标题：显示空状态提示

2. 用户滚动正文
   → 计算当前所在标题（视口内最靠上且已越过视口顶部的标题）
   → 大纲中对应条目高亮更新（仅高亮，不移动大纲自身滚动条）

3. 用户点击某条大纲标题
   → 内容区 `smooth` 滚动到该标题所在位置
   → 该条目临时高亮，随后恢复为"当前"状态

4. 用户点击面板标题栏 `[`×]` 或快捷键（若定义）
   → 面板整体折叠
   → 再次点击右侧恢复按钮展开
```

## 4. 功能详述

### 4.1 标题提取
- 遍历 `#content` 下的 `h1 ~ h6` 元素，按文档顺序生成扁平列表。
- 每条目记录：`text`（标题文本，含空格规范化）、`level`（1~6）、`element`（对应 DOM 元素引用）。
- 层级仅影响缩进与图标显示；大纲面板本期不实现"父子嵌套折叠"树（扁平列表 + 缩进即可满足需求）。
- 标题文本去首尾空白；含代码块的标题保留源码文本展示（如 `` 安装 `` → `安装`）。

### 4.2 与内容区的双向定位
- **高亮跟随**：内容区滚动时，通过 `scroll` 事件（配合 `requestAnimationFrame` 节流）计算当前活跃标题。
- **点击跳转**：点击条目后 `element.scrollIntoView({behavior:'smooth', block:'start'})`，并在顶部预留偏移（`scroll-margin-top`）避免贴顶。
- **定位精度**：以 DOM 标题为锚点，精确对齐标题元素，优于搜索的近似行映射；因为标题 → 头元素 → 元素本身。

### 4.3 面板折叠/展开
- 折叠状态记忆（`localStorage`），下次打开应用保持上次折叠状态。
- 折叠后展开方式：右侧窄条按钮或再次点击标题栏。

### 4.4 与搜索功能的协同
- 共享 `rawMarkdown` 状态变量与 DOM 滚动手段，互不冲突。
- 打开新文件时：重建大纲、清空折叠残留高亮。

## 5. 数据流与状态（无新增 IPC）

```
renderer.js
  ├─ renderMarkdown(content, filePath)
  │     └─ 渲染后 → buildOutline() → 生成 #outline-panel 条目
  │
  └─ 大纲交互（纯渲染进程）
        ├─ 滚动监听 → highlightActiveOutline(heading)
        └─ 点击 → scrollIntoView + 临时高亮
```

**新增状态变量**：
- `outlineItems`：`Array<{ level, text, headingElement }>` 大纲条目集合。
- `activeOutlineIndex`：当前高亮条目下标（`-1` 表示无）。
- `outlineCollapsed`：面板折叠状态（可持久化）。

**不新增 IPC**：大纲完全基于已渲染 DOM，符合 `contextIsolation` 安全边界。

## 6. 错误处理与边界情况

| 场景 | 行为 |
| :--- | :--- |
| 未打开任何文件 | 大纲面板隐藏或显示空状态，不报错 |
| 文档无任何标题 | 显示"该文档暂未检测到标题"空状态提示 |
| 标题层级跳跃（H1→H3 无 H2 中间层） | 按实际层级展示，缩进随实际层级，不强制补齐 |
| 超大文档（标题极多） | 大纲面板自身可滚动，不影响正文；提取与高亮计算节流 |
| 引用格式标题（源码含 `#` 于代码块） | 大纲仅基于渲染后的 `h1~h6`，代码块内 `#` 不会误判（markdown-it 已做块级区分） |
| 打开新文件 | 重建大纲、重置 `activeOutlineIndex`、清空高亮 |
| 面板折叠状态下打开新文件 | 保持折叠记忆状态，仅更新内部大纲内容 |

## 7. 验收标准（AC）

1. **[提取] 打开含 H1~H3 多级标题的 `.md`，右侧大纲按层级缩进完整展示所有标题。**
2. **[定位] 点击大纲中任一标题，内容区平滑滚动到该标题位置并正确高亮。**
3. **[跟随] 滚动正文时，大纲当前项随阅读位置自动切换高亮。**
4. **[折叠] 点击 `[×]` 面板折叠不遮挡正文；再次展开后大纲内容保留。**
5. **[折叠记忆] 折叠状态在应用重启后得以保持（若实现持久化）。**
6. **[空状态] 打开无标题文档，显示友好空状态而非空白。**
7. **[安全]** 大纲逻辑不新增 IPC、不访问 `fs`；`contextIsolation` 边界不变。
