# Markdown 阅读器功能TODO需求文档

## 模块一：代码块增强

### 2.1 功能目标

为 Markdown 预览中的代码块添加语言标识、行号显示和一键复制功能，提升代码阅读体验。

### 2.2 用户故事

- 作为用户，我希望代码块上方显示语言名称标签
- 作为用户，我希望代码块左侧显示行号（不可选中）
- 作为用户，我希望能一键复制代码块的全部内容
- 作为用户，我希望鼠标悬停时工具栏才出现（不干扰阅读）
- 作为用户，我希望复制成功后能有短暂的视觉反馈
- 作为用户，我希望长代码块（>30行）默认折叠，可展开



## 模块二：Mermaid 流程图渲染

### 3.1 功能目标

识别 Markdown 中的 Mermaid 代码块，将其渲染为可交互的 SVG 图表，支持缩放查看和导出。

### 3.2 用户故事

- 作为用户，我希望 ````mermaid` 代码块能自动渲染为图表
- 作为用户，我希望图表在深色/浅色主题下都有合适的配色
- 作为用户，我希望看到渲染错误时有友好的错误提示
- 作为用户，我希望图表支持缩放查看（点击放大）
- 作为用户，我希望能将图表导出为 SVG 或 PNG 图片
- 作为用户，我希望图表渲染不影响页面滚动性能
